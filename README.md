# TestPRAdvisor2

Proyecto de prueba para validar las funcionalidades de **PullRequestAdvisor**.

## Estructura

```
src/
  index.js          — punto de entrada
  auth/
    login.js        — autenticación de usuarios
    token.js        — gestión de tokens
  payments/
    checkout.js     — procesamiento de pagos
    invoice.js      — generación de facturas
    refund.js       — devoluciones
  notifications/
    email.js        — envío de emails
    sms.js          — envío de SMS
  utils/
    logger.js       — utilidades de log
    validator.js    — validaciones comunes
```
